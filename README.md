# IDP - Introduction to Dart Programming
Exam Practical Paper

## Yêu cầu đề bài
- Tạo class `Order`
- Đọc nội dung từ JSON string và lưu vào danh sách orders
- Tạo website hiển thị danh sách order
- Thêm order và lưu vào file `order.json`
- Tìm kiếm order theo `ItemName`

## Hướng dẫn chạy
- Chạy web: `flutter run -d chrome`
- Chạy file kiểm tra logic: `dart run test_order.dart`
